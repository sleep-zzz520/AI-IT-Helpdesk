# 新员工入职指南

## 入职流程

新员工入职当天办理：

1. 携带身份证与学历证明到人力资源部（3 号楼 2 层）办理入职手续
2. 领取工牌与门禁卡（临时卡，正式卡 3 个工作日后发放）
3. 签订劳动合同（一式两份）与保密协议
4. 参加入职培训（每周一、三下午，时长 2 小时）

## 薪酬与考勤

- 工资卡：入职后第 2 个工作日由财务部统一办理
- 考勤制度：弹性工作制，核心时段 10:00–16:00，其余时间可自由安排
- 请假流程：OA 系统提交申请 → 直属主管审批 → HR 备案

## 常见问题

- 工牌丢失：在 HR 前台登记补办，工本费 30 元
- 门禁失效：联系行政部（分机 8001）
- 入职材料不全：请在 5 个工作日内补齐，否则影响当月工资发放
