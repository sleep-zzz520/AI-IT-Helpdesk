# 办公软件更新策略

## 更新渠道与节奏

- 办公软件（Office、浏览器、聊天工具）由软件中心统一推送，每月第 2 周发布
- 安全补丁（操作系统、防病毒）按紧急程度随时推送，重启后生效
- 业务系统（财务、人事）由各系统管理员维护，不通过软件中心

## 更新规则

- 软件中心推送的更新**自动安装**，无需用户操作；部分更新需重启电脑
- 用户可将更新推迟最多 14 天（手动点"稍后提醒"）
- 被推迟超过 14 天的更新强制执行，强制更新前 3 天每天弹窗提醒

## 常见问题

- 更新后软件打不开：先重启电脑，仍有问题联系服务台提供"回滚版本"包
- 不想用新版本（如 Office 新界面不适）：支持回退到上一个版本，保留 2 个历史版本
- 更新安装失败"0x80070643"：空间不足或安装源损坏，清空临时目录后重试

## 与安装故障的区别

本指南覆盖"更新/补丁"；新装软件、许可证激活问题
见《办公软件安装与授权指南》《软件许可证激活与常见报错》。
