# 软件许可证激活与常见报错

## 症状与判断

- **提示"许可证无效 / 产品密钥错误"**：密钥输入错误，或密钥类型与版本不匹配（企业版 vs 个人版、Office 2021 vs 365）
- **提示"激活次数超限"**：许可证绑定设备数达到上限，通常是离职/换机设备未释放授权
- **提示"无法连接激活服务器"**：网络问题——代理/防火墙拦截了激活域名
- **安装后反复提示激活**：许可证未正确分配到当前设备（设备不在企业授权名单）

## 处理步骤

1. 核对密钥类型与软件版本一致（企业批量许可 ≠ 零售密钥，混淆是激活失败的头号原因）
2. 检查网络：激活服务器域名是否被防火墙/代理拦截，排除后重试激活
3. 企业版：确认设备是否在 IT 分配的授权名单（批量激活），不在名单先走资产登记
4. 激活次数超限：联系 IT 管理员释放旧设备占用，或迁移授权到当前设备
5. 全部核对无误仍失败：收集错误码和安装日志，转人工联系软件供应商支持

## 风险说明

许可证操作属**低风险**；唯一涉及人工的是授权迁移（需管理员在授权后台操作，用户不能自助）。

## 注意事项

- **不要使用非官方激活工具**（破解/激活器有安全风险），一律走正规授权流程
- 卸载重装前先确认许可证可回收（先取消本机激活），避免"装一次少一个名额"
- 批量许可环境下，激活状态异常先查设备是否在名单，再查密钥，顺序反了容易误导排查
