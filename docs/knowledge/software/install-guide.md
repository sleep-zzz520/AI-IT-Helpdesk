# 办公软件安装与授权指南

## 症状与判断

用户报障"软件问题"的常见类型：

- **申请安装软件**：需要办公套件、IM 工具、业务系统客户端
- **授权/激活失败**：提示"许可证无效"或"产品密钥被占用"
- **软件损坏**：启动崩溃、功能异常（多为升级中断或杀软误删组件）
- **版本不符**：新员工电脑自带家庭版软件，不符合企业授权

需要收集的信息：软件名称、操作系统（Windows/macOS）、授权类型（企业批量授权/个人授权）。

## 处理步骤

1. 确认软件在企业软件白名单内（未授权软件走特殊审批）
2. 从**企业软件分发平台**下载安装包（不要从个人渠道下载，防捆绑/恶意软件）
3. 安装后执行企业授权激活（批量授权 KMS / 账号激活）
4. 激活失败排查：确认系统时间准确（KMS 激活对时间敏感）→ 确认网络能访问激活服务器 → 确认设备已入域
5. 验证软件可正常启动

## 风险说明

软件安装属于**中风险操作**：涉及系统级变更，安装时需用户在场确认，不能全自动静默安装。

## 注意事项

- **禁止**从非官方渠道下载安装包（供应链攻击风险）
- 激活失败先查系统时间（KMS 激活的经典坑）
- 企业授权软件离职需回收授权（交接流程）
