# VPN 客户端配置指南

## 适用场景

证书状态正常（未过期）但 VPN 仍然连不上（常见 Error 800）。此时问题大概率出在**客户端配置**而非账号。

## 常见配置问题

### 代理设置干扰

- 系统代理或浏览器代理接管了 VPN 流量，导致连接被劫持
- 检查：系统设置 → 网络 → 代理，确认未开启全局代理
- 解决：关闭代理或为 VPN 网关添加绕过列表

### 路由表异常

- 公司内网网段未正确写入路由表，拨号成功但无法访问内网资源
- 检查：`route print` 查看路由表中是否有公司网段
- 解决：重新安装客户端触发路由重建

### 配置文件损坏

- 上次异常退出导致配置文件损坏
- 检查：客户端报"配置解析失败"
- 解决：删除配置文件重新登录（会重新下发配置）

## 排查顺序

1. 确认证书正常（避免和证书问题混淆）
2. 检查代理设置
3. 检查路由表
4. 重置客户端配置

## 注意事项

- **不要**在证书未确认的情况下直接重置配置（会白费一轮操作）
- **不要**卸载重装客户端（重装无法解决代理/路由问题，且耗时长）
