# VPN 错误码速查手册

## Error 800

**无法建立 VPN 连接**。最常见原因是**证书过期**或客户端配置损坏。

排查顺序：
1. 查证书状态：过期 → 续期（见《VPN 证书续期 SOP》）
2. 证书正常 → 检查客户端配置是否被篡改（代理设置、路由表）
3. 配置异常 → 重置为默认配置

处理：证书过期执行 `vpn.renew_certificate`；配置问题执行 `vpn.check_client_config`。

## Error 720

**无法建立与远程计算机的连接**。通常是拨号连接组件损坏（系统更新/杀软误删导致）。

处理：重建拨号连接（删除旧连接 → 重新创建 → 拨号）。执行 `vpn.rebuild_connection`。

## Error 721

**远程计算机无响应**。多为网络链路问题：公司网关不可达、DNS 解析失败。

处理：检查网络连通性（ping 网关）→ 检查 DNS → 排除本地网络后重试。**不需要动证书和客户端配置**。

## Error 809

**无法建立计算机与 VPN 服务器之间的网络连接**。多为防火墙/安全软件拦截或网络环境变更。

处理：检查系统防火墙是否放行 VPN 客户端 → 检查安全软件 → 切换网络（如从公司网切到家庭网）重试。

## Error 812

**连接被策略阻止**。账号被禁用、设备不在白名单、或多设备同时在线。

处理：检查账号状态（是否被锁定）→ 确认设备登记 → 若多设备在线，踢掉旧会话。

## 通用排查原则

1. **先查证书**（80% 的 800 错误都是证书过期）
2. **再查配置**（证书正常才怀疑客户端配置）
3. **最后查网络**（721/809 才是网络问题）
4. 每个错误码的解决方案不同，**不要用同一个方案硬套**
