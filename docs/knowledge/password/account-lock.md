# 账号锁定与解锁

## 症状与判断

登录连续失败多次（通常 5 次）触发安全锁定，登录时提示"账号已锁定"。

常见原因：

- **忘记密码反复尝试**：用户密码记忆模糊，多次输入错误
- **暴力破解攻击**：攻击者批量尝试密码，账号被风控锁定
- **异地登录风控**：在非常用设备/位置登录触发安全策略

关键区分：**密码错误**（可继续尝试，提示"用户名或密码不正确"）vs **账号锁定**（直接拒绝登录，提示"已锁定"）。锁定比密码错误更严重——必须先确认锁定原因，不能直接解锁。

## 处理步骤

1. 确认锁定原因：查登录日志（失败来源 IP、时间点、失败次数），区分人为失误 vs 攻击
2. 人为失误（错误次数多、来源正常）：验证身份（工号 + 手机验证码 / 直属主管确认）后解锁
3. 疑似攻击（异常 IP、高频尝试）：**不立即解锁**，冻结账号 + 通知安全团队（防止攻击者继续爆破）
4. 解锁成功后：要求用户设置新密码，**不能复用旧密码**（策略强制）
5. 全程记录审计日志（操作人 / 时间 / 解锁原因 / 是否冻结）

## 风险说明

解锁属于**中风险操作**：解锁前必须确认不是暴力破解攻击，否则等于帮攻击者把门打开。身份验证缺失时**不得**解锁——这是安全红线。

## 注意事项

- 解锁后提醒用户更新所有设备的登录态（旧会话可能仍被锁定）
- 连续多次解锁请求本身可能是攻击信号（试探账号价值），需升级安全团队
- 与"密码重置"的配合：锁定 + 遗忘场景通常是"先解锁再重置"，见密码重置 SOP
