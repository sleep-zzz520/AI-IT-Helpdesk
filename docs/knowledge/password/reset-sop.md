# 企业密码重置 SOP

## 症状与判断

用户报障"密码"相关问题的常见类型：

- **忘记密码**：多次尝试失败，账号被临时锁定
- **密码过期**：登录时提示"密码已过期，请修改"（企业安全策略通常 90 天强制改密）
- **无法自助重置**：自助找回流程失败（手机号变更、安全问题忘记）

需要收集的信息：用户名（域账号），用于定位账号和验证身份。

## 处理步骤

1. 验证用户身份（工号 + 手机验证码 / 直属主管确认）
2. 通过账号管理平台执行密码重置（临时密码，首次登录强制修改）
3. 若账号被锁定：先解锁再重置
4. 告知用户临时密码与修改要求（8 位以上，含大小写+数字+特殊字符）

## 风险说明

密码重置属于**中风险操作**：涉及账号安全，必须**人工确认身份**后才能执行，不能全自动。执行记录需进入审计日志。

## 注意事项

- 临时密码**必须**要求首次登录修改，防止中间人利用
- 重置后原密码立即失效，需提醒用户退出其他已登录设备
- 锁定账号需先确认不是暴力破解攻击（异常登录日志），再决定解锁还是冻结
