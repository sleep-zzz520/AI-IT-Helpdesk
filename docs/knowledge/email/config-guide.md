# 企业邮箱配置指南

## 症状与判断

用户报障"邮箱问题"的常见类型：

- **新设备配置邮箱**：不知道服务器地址、端口、协议
- **收不到邮件**：接收服务器配置错误、密码错误、客户端权限
- **发不出邮件**：SMTP 认证失败、被反垃圾策略拦截（Error 553/554）
- **附件限制**：超过单封邮件大小上限（通常 50MB）

需要收集的信息：设备类型（手机/电脑）、邮箱客户端（Outlook/手机自带/第三方）、故障方向（收/发/都收不到）。

## 服务器参数

| 协议 | 服务器 | 端口 | 加密 |
|---|---|---|---|
| IMAP | imap.company.com | 993 | SSL |
| SMTP | smtp.company.com | 465 | SSL |

## 处理步骤

1. 确认用户使用的客户端与协议
2. 按上表参数配置（重点核对加密方式，SSL 端口不能写成明文端口）
3. 收不到：检查 IMAP 认证 → 检查客户端"以授权码代替密码"设置
4. 发不出：检查 SMTP 认证 → 检查是否触发反垃圾策略（短时间内大量群发）
5. 验证收发各一封测试邮件

## 风险说明

邮箱配置是**低风险操作**：不涉及账号权限变更，只指导用户填写配置。可自动提供配置参数，无需执行系统操作。

## 注意事项

- 企业邮箱通常**禁止用明文密码**，必须用"客户端授权码"（在邮箱安全中心生成）
- 换设备后旧设备的授权码不失效，安全考虑建议提醒用户吊销不用的设备授权
