# 邮件收发故障排查

## 症状与判断

- **收不到邮件**：IMAP/POP3 认证失败、服务器地址配置错误、客户端权限被撤销
- **发不出邮件**：SMTP 认证失败、被反垃圾策略拦截、附件超限（单封 > 50MB）
- **常见报错**：553（发件人身份不被认可）、554（被反垃圾拒绝）、"无法连接到服务器"

排查第一步永远是分清方向：**收不到 / 发不出 / 都异常**——决定查 IMAP（收）还是 SMTP（发）配置，方向错了会白查一圈。

## 处理步骤

1. 先分清方向：收不到查 IMAP 配置，发不出查 SMTP 配置，都异常先查账号密码
2. 核对服务器参数（参照企业邮箱配置指南）：IMAP 993 加密 / SMTP 465 加密（或 25/587 明文）
3. 确认账号密码正确——**特别注意：改过密码后客户端会静默失败**，需更新所有客户端
4. 检查安全设置：新设备/新客户端常被"客户端授权"功能拦截，需在邮箱后台开启授权
5. 排除反垃圾：发不出时先确认收件方地址拼写，再检查拦截通知（垃圾箱 / 隔离区）
6. 仍失败：收集报错原文和截图，转人工联系邮件管理员

## 风险说明

排查属**低风险只读操作**：不涉及账号密码修改，客户端配置改动由用户自行完成，无需人工审批。

## 注意事项

- **密码重置后（见密码重置 SOP）必须同步更新所有客户端的密码**——这是"改完密码就收不到邮件"的第一排查点，80% 的此类工单都是客户端还在用旧密码
- 不要在聊天/工单中明文传输密码
- 企业邮箱通常限制单设备同时在线数，超出后旧设备会掉线
