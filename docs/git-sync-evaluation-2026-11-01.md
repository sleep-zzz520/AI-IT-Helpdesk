# Git 增量同步验收报告

日期：2026-11-01。数据来自本地隔离验收；公网部署结果以 GitHub Actions 发布记录为准。本报告不把练习测试计入应用回归，也不将同步正确性当作模型回答准确率。

## 实现范围与取舍

发布来源先限定为受控 Git Markdown。CI 从通过检查的固定提交枚举树、读取 blob、生成含原始字节和 SHA256 摘要的快照；容器只读导出文件，入队前将快照持久化至命名卷。16 篇存量文档通过显式 UUID 映射迁移；新文档须提供 UUID，复制 ID 整轮失败。非法 YAML、读取失败、符号链接、子模块、LFS 指针、隐式图片依赖、超限或不支持格式均失败关闭，不能变成空清单。空来源禁止自动发布。

MySQL 保存来源意图与持久任务，后台 worker 领取、续租、构建；崩溃后过期任务可重新领取，最多恢复三次。任务目标不可改写，同源新意图使旧任务不能发布。处理过程中不持有等待模型的数据库事务。发布在同一短事务内锁定来源并检查当前序号、任务状态与 pipeline profile；租约/fencing 检查用于构建完成阶段。首版仍依赖同机文件锁保证构建产物只有一个写者。

每个版本对应独立完整 Chroma collection，未变块复制已有向量，变化输入通过按 source/profile/实际清洗文本隔离的缓存复用。父块只用于回填，保存完整正文，使用零向量且不参与向量召回；长子块显式拆小，避免尾部修改被截断遗漏。发布和回滚都验证精确块清单、正文、metadata、向量维度和 BM25 可构建性。读取丢失的版本不会自动创建空库。

同一轮回答的多次检索固定一个版本。BM25 缓存按持久目录、版本与删除限制摘要隔离。确认删除/停用先写独立限制，即使其他文档构建失败，旧代也不得返回该文档。父块回填、裁判前、生成前后和执行前再次检查；回滚不撤销删除限制。已经发给供应商的内容无法事后撤回，本版不承诺零时延撤销。

该实现以完整索引复制换隔离和可回滚，适合当前 16 篇规模。它实现嵌入计算增量，不承诺全部索引写入增量。无自动物理回收，存储随保留代数增长；最多 512 篇、单篇 2 MiB、原始内容合计 16 MiB 是输入限制，不是已验证的容量 SLO。

## 故障、接口与界面验收

- Git 来源 60 项：真实临时 Git、HEAD 推进、未提交修改、改名保 UUID、非法身份/格式、导出损坏与原子写入失败。
- 版本同步 24 项：真实 SQLite/Chroma，初始化、重复任务、向量复用、长文尾部、部分写入失败、租约恢复、旧任务过期、profile 隔离、删除/恢复与回滚。
- API/Agent 边界 12 项：真实认证与 HTTP 202 任务受理、任务状态、发布/回滚、非管理员拒绝；回答多跳固定代，删除在裁判/生成/执行边界生效。
- 真实 MySQL 额外验证：10 请求并发首次入队得到同一任务；已发布目标并发重复提交仍复用同一任务。它不代替多机、长时压测或所有数据库故障场景。
- 真实 Embedding 故障注入：一篇确认删除，另一篇嵌入失败时在岗指针保持；被删文档不再出现在旧代读取中，回滚也不恢复它。
- 浏览器验收使用隔离 SQLite/Chroma 和确定性嵌入：同步、准备、确认发布、16 篇/80 块展示、重复同步、刷新恢复均正常；隔离 SQL 核验只有一个 published 任务。界面测试未调用真实回答模型。

部署前运行完整后端回归与 Ruff、前端测试/lint/build。部署工作流备份 SQL 与知识卷，拒绝过期 main 提交；后端启动后构建/验证/发布固定 Git 来源，再执行真实双路召回和父块回填验收。单纯 `/health` 成功不足以判定新链路已上线。

本地完整回归：299 项后端测试通过，Ruff 通过；16 项前端测试通过，lint/build 通过。保留第三方弃用警告和两条既有 React Hook 提示，不将其写成零警告。

## 尚未覆盖

知识来源在本版是显式共享的 IT 资料，不具备文档级租户 ACL。同机部署之外的分布式租约与产物持久化、自动 GC、外部 Wiki 增量游标、多格式版本缓存、供应商静默换权重检测均未交付。同步任务当前提供失败原因和管理员重新提交；不是完整的错误分类、自动重试退避和运营告警系统。真实流量下的 p95、删除最坏生效时延、长期磁盘增长及容灾恢复演练仍需上线后测量。
