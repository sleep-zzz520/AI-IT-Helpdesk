# 检索规模与同领域干扰测评协议

本轮测量检索层，不测问答生成、工具执行或上线容量。业务检索算法与参数保持当前配置，Rerank 关闭。旧 60 题作为单独回归，不与新题合并。协议在查看新测试分数前写定；标注审查完成后冻结数据 SHA-256，冻结后不按成绩改题或调参。

新集目标为 50 个问题家族、300 道不同事实任务，按整个家族隔离开发集和测试集（10/40 家族，60/240 题）。每档共同保留全部目标文档，扩大规模只增加带冲突条件的运维干扰文档。使用固定种子 20261102、20261103、20261104，每种子内 64/256/512 篇嵌套。语料与题目为模型辅助撰写的合成企业手册，内部约定不代表真实厂商规范。独立代理在看分数前核查证据与抽查语义，仍不等于人工专家金标准。

主对照调用现有 `retrieve_vector_only` 和 `retrieve`，共享真实 Embedding-3 查询向量、Chroma 索引、向量阈值、候选数量、来源限制与有效性字段。额外 BM25-only 消融沿用当前 BM25 召回、过滤、来源限制，观察词法路贡献，不据此声称每项机制都有独立因果收益。使用生产 `split_markdown`，不把标题或文档 ID 加入嵌入文本。父块沿用零向量且不参与排序，只回填上下文。

主指标为逐题必需 Gold 子段覆盖率的宏平均 Recall@1/3/5，MRR 为第一个必需 Gold 的倒数排名，截断于 5；多 Gold 题另报 Top-5 全证据覆盖和父文档覆盖。无答案、停用和过期探针不进入可回答题 Recall 分母；无答案只观察是否返回结果，不能用空结果代表正确拒答。错误保留在尝试分母，不能删除失败题。

记录逐题排名、双路候选与融合阶段、错误、方法配对进退、规模变化退化，以及按题型/集合分层统计。三个随机干扰集合是稳定性检查，不是三个独立问题集；置信区间须按问题家族配对重采样，不能把同题三次视为独立样本。

真实 API 按清洗后文本、模型和维度缓存，所有方法与规模复用同一内容及查询向量。记录请求级耗时和输入数量；批量请求耗时不能除后当作线上单问延迟。索引构建、BM25 首次加载、暖检索耗时分开计量。查询批处理包含上游网络与服务端时间；检索计时包含 Chroma 查询、父块回填和当前方法代码，不含查询向量计算。交替方法执行顺序，操作系统页缓存不清空；暖检索至少 240 个不同测试问题后可给本机描述性 p95，不解释为线上 SLO。

本轮只创建独立本地 Chroma，不连接生产 SQL、不运行同步发布、不修改生产知识库。保留原始输入、输入清单、SHA-256、源码提交与工作区状态、相关代码哈希、参数、种子、API 事件、逐题结果和可复现命令。完整输入与向量缓存留在 `.rag/evaluations/retrieval-2026-11-02/`，现有旧报告不覆盖。
